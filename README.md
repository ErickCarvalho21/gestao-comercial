# Sistema de Gestão Comercial

Sistema web desenvolvido para agilizar o atendimento em um pequeno comércio, permitindo o cadastro de produtos, controle de estoque, vendas e caixa.

## Objetivo

Reduzir a lentidão no atendimento do caixa e automatizar o processo de identificação de produtos, cálculo de vendas e atualização de estoque.

## Funcionalidades planejadas

- Cadastro de produtos
- Leitura de código de barras
- Produtos vendidos por unidade e por peso
- Controle de estoque
- Registro de vendas
- Pagamentos via dinheiro, PIX e cartão
- Controle de caixa
- Perfis ADMIN e FUNCIONARIO
- Relatórios

## Tecnologias

- Java
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Spring Security
- Swagger/OpenAPI
- Docker
